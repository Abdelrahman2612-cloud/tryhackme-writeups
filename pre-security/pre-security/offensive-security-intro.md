# Offensive Security Intro

**Platform:** TryHackMe | **Path:** Pre-Security

## Goal
Understand what offensive security is and how it differs from defensive work.

## Key concepts
- Offensive security means thinking like an attacker to find weaknesses before a real attacker does.
- Defenders (blue team) use what offensive work finds to close gaps and improve detection.
- Finding a weakness safely means working inside a legal, authorised scope.

## Tools and methods
- Hands-on task in an in-browser lab: probing a simulated target to find hidden pages.

## Takeaways
- Offensive and defensive security depend on each other.
- Knowing how an attack works makes it easier to spot in logs and alerts, which is the direction I'm heading (SOC and blue team).
